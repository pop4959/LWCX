# LWC Extended

The unofficial continuation of LWC, supporting newer versions of Minecraft.

### Downloads
LWCX has separate builds for Paper and Spigot. Make sure to use the one that matches your server:

| Server | Stable releases | Development builds |
|---|---|---|
| **Paper** (and forks) | [Modrinth](https://modrinth.com/plugin/lwc) | [CodeMC – LWC Paper](https://ci.codemc.io/view/Author/job/pop4959/job/LWC%20Paper/) |
| **Spigot** / CraftBukkit | [SpigotMC](https://www.spigotmc.org/resources/lwc-extended.69551/) | [CodeMC – LWC](https://ci.codemc.io/view/Author/job/pop4959/job/LWC/) |

Each build only runs on its own platform: the Spigot build won't load on Paper, and the Paper build won't load on Spigot. For older Minecraft versions, see the [installation guide](https://github.com/pop4959/LWCX/wiki/Installation) for which build to use.

### Support
For reporting problems with the plugin, please make an issue here on GitHub. For anything else, feel free to join us on the [M.O.S.S. Discord server](https://discord.gg/PHpuzZS). Before asking for support, please make sure you have an updated version of the plugin first.
  
### Information
LWC is the longest-lived single block protection plugin, that protects both the blocks themselves and their contents. Originally designed in 2010 for locking chests (hence the name "Lightweight Chests"), it can be configured to lock any block.

Please see our [wiki](https://github.com/pop4959/LWCX/wiki) for important information about setting up and using the plugin.

### Contributing
Contributing to LWCX is encouraged, and very easy. Fork the repository, and build using Gradle. Simply make a pull request explaining your changes, and how they are a beneficial addition to the plugin. Github Actions will automatically build all pull requests.
